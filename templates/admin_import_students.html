File Requirements

Your Excel/CSV file should include these columns:

  • Option 2 first_name, middle_name, last_name - Separate columns

Import Help
Student Import Guidelines

This form allows you to add new students to the system either individually or in bulk.

Manual Entry

You can enter student information manually with two options:

  • Single Name Field: Enter the full name and it will be automatically parsed into first, middle, and last name components.
  • Separate Name Fields: Toggle the switch to enter first, middle, and last names separately.
Bulk Import

For importing multiple students:

  • Use Excel (.xlsx, .xls) or CSV (.csv) files
  • Download the template for the correct format
  • The system supports both full name in a single column or separate name columns
  • First row should contain column headers
Name Parsing: When using a single name field, the system will automatically parse Filipino names into first, middle, and last name components.
